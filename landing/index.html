Local Process Flow

See exactly how Genix AI queries files, filters chunks, and serves private responses securely on-device.

Step 01 · Import Sandbox

Import & Store Locally

Your target PDFs or text files are imported straight into the application's isolated local database storage directory. At no point do these files connect to, or pass through, any central server or network node.

Step 02 · Text Processing

On-Device Text Indexing

The application reads the document, performs smart sentence boundaries evaluation, and breaks the text into structured semantic chunks. A local vector index structure is generated instantly in native system RAM.

Step 03 · Similarity Search

Cosine Similarity Search

When you enter a prompt, the application encodes the query text locally and performs high-speed cosine similarity match calculations against the loaded document chunks. The highest scoring contexts are retrieved instantly.

Step 04 · Synthesis

Quantized Model Generation

The localized context chunks are structured and passed as strict prompts to the quantized Gemma 2B model context. The model generates answers word-by-word right on your processor with zero network activity.
